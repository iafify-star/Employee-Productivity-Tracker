# مؤشر الإنتاجية

لوحة عربية لمتابعة إنتاجية السورتينج والـ staging مباشرة من Google Sheets.
تتضمن شعار noon MINUTES، وتدعم العربية والإنجليزية مع مظهر نهاري وداكن.

## التشغيل

افتح `index.html` باستخدام خادم محلي (مثل إضافة Live Server في VS Code)، ثم افتح الرابط المحلي في المتصفح. يجب أن يكون الشيت متاحًا للعرض لمن لديه الرابط، وأن يتوفر اتصال بالإنترنت لتحميل بياناته والخط.

## طريقة الحساب

- **السورتينج:** يجمع `sorted_qty` حسب `sorter` وساعة `job_completed_at`، ويعرض بيانات يوم `job_completed_at` المختار.
- **الـ staging:** يحسب عدد قيم `container_barcode` الفريدة لكل `staged_by`، ويعرض سجلات يوم `staged_at` المختار.
- **أسماء الموظفين:** يطابق بداية اسم المستخدم مع عمود `ID` في تبويب `CAIID01` من شيت الحضور، ويعرض `Employee Name` فوق اسم المستخدم.
- يمكن تغيير التاريخ، البحث عن موظف، أو تحديث بيانات الشيت يدويًا.
- زر **تحميل Excel** ينزّل ملفًا بالتاريخ المختار يحتوي على ملخص، وبيانات السورتينج حسب الساعة، وملخص الحاويات لكل موظف staging. التصدير يشمل كل الموظفين في التاريخ المحدد حتى لو كان حقل البحث مفعّلًا.
- يمكن تبديل اللغة والمظهر من الشريط العلوي؛ يتم حفظ التفضيلات في المتصفح.
