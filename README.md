# مؤشر الإنتاجية

لوحة عربية لمتابعة إنتاجية Sorting batch وSorting XDOCK والـ staging مباشرة من Google Sheets.
تتضمن شعار noon MINUTES، وتدعم العربية والإنجليزية مع مظهر نهاري وداكن.

## التشغيل

افتح `index.html` باستخدام خادم محلي (مثل إضافة Live Server في VS Code)، ثم افتح الرابط المحلي في المتصفح. يجب أن يكون شيت الإنتاج متاحًا للعرض، وشيت الحضور منشورًا للويب بصيغة CSV، وأن يتوفر اتصال بالإنترنت لتحميل البيانات والخط. إذا تعذر الوصول إلى شيت الحضور، ستظل بيانات الإنتاج متاحة وسيظهر username بدل اسم الموظف مع تنبيه.

## طريقة الحساب

- **السورتينج:** يجمع `sorted_qty` حسب `sorter` وساعة `job_completed_at`، ويعرض `skipped_qty` لكل مستخدم وإجماليه لليوم المختار.
- **Sorting XDOCK:** يجمع `put_away_lines` لكل `username` حسب وقت بدء المهمة `job_started_at`، مع تطبيق تاريخ وساعات العمل المختارة.
- **الـ staging:** يحسب عدد قيم `container_barcode` الفريدة لكل `staged_by`، ويعرض سجلات يوم `staged_at` المختار.
- يمكن تحديد وقت بداية ونهاية العمل لتصفية الداشبورد والأقسام الثلاثة؛ ساعة البداية والنهاية مشمولتان، واختيار نهاية أسبق من البداية يفعّل نطاقًا يعبر منتصف الليل لليوم التالي.
- **أسماء الموظفين:** يطابق بداية اسم المستخدم مع عمود `ID` في تبويب `CAIID01` من شيت الحضور، ويعرض `Employee Name` فوق اسم المستخدم.
- يمكن تغيير التاريخ، البحث عن موظف، أو تحديث بيانات الشيت يدويًا.
- زر **تحميل تقرير Excel** ينزّل تقريرًا باللغة الإنجليزية بشعار noon MINUTES وصفحة ملخص لإجمالي إنتاج Sorting batch وSorting XDOCK وStaging، وصفحة متابعة التسليم. يملأ المتبقي تلقائيًا من `pending_qty` للسورتينج و`not_put_away_lines` للـ XDOCK، ويترك خانات Staging وDS وTotes للتعبئة اليدوية، مع الحالة والملاحظات. لا يتضمن التقرير بيانات موظفين.
- زر **تنزيل الجدول Excel** داخل جدولي Sorting batch وSorting XDOCK يصدّر بيانات الجدول حسب التاريخ والساعات المختارة، ويحترم البحث الحالي، مع صف إجمالي في نهاية كل ملف.
- يمكن تبديل اللغة والمظهر من الشريط العلوي؛ يتم حفظ التفضيلات في المتصفح.
- صفحة **نظرة عامة** تعرض إجماليات الأقسام الثلاثة، عدد الموظفين النشطين، مخططًا لإنتاج السورتينج بالساعة، وقوائم أعلى الموظفين إنتاجًا حسب التاريخ المختار.
